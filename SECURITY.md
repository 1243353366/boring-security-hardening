# Security policy

## Scope

This repository provides general defensive hardening and incident-response guidance. It is not a service, product, or authorization to test any system. Only assess devices, accounts, networks, and services that you own or are explicitly authorized to administer.

## Safe-use expectations

- Keep contributions focused on prevention, detection, evidence preservation, containment, and recovery.
- Do not submit secrets, credentials, personal information, private logs, or unredacted incident artifacts.
- Do not use this repository to coordinate unauthorized access, surveillance, disruption, or data collection.
- Follow applicable laws, organizational policy, and vendor documentation.

## Reporting a concern in this repository

For an issue with the documentation or project, open a GitHub issue with a concise description and steps to reproduce the documentation problem. Do not include sensitive information. If a report concerns a real-world compromise, contact the affected organization or service provider through its official security-reporting channel rather than posting details publicly.

This repository does not currently publish a dedicated private vulnerability disclosure contact. Do not disclose sensitive vulnerabilities or exploit details in public issues.

## Disclaimer

Guidance is provided “as is,” without guarantees. Security controls should be adapted to the environment and validated by qualified personnel where appropriate.
